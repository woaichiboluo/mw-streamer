MPEG-2 non-keyframe/AAC input scheduling fixture

Generated from FFmpeg testsrc2 and sine sources, without external media.
Video: 64x64, 10 fps, MPEG-2; 79 decoded P frames and no keyframes.
Audio: 48 kHz mono AAC, 32 kbit/s; starts at zero and lasts about 8 seconds.
Size: 126336 bytes.

The MPEG-2 sequence/GOP headers are retained, but the first I picture is
removed. FFmpeg can therefore initialize the decoder and produce non-key
frames before any usable keyframe exists. This checks that waiting for a video
keyframe does not block OnReady or audio delivery.

Generation with FFmpeg 8.1.3 (BtbN build, 2026-10-04):

ffmpeg -f lavfi -i "testsrc2=size=64x64:rate=10:duration=8" \
  -c:v mpeg2video -g 100 -bf 0 -q:v 10 -f mpeg2video mpeg2_long.m2v

Remove the first picture while retaining the leading sequence/GOP headers:

from pathlib import Path
data = Path("mpeg2_long.m2v").read_bytes()
starts = [i for i in range(len(data)) if data[i:i+4] == b"\x00\x00\x01\x00"]
Path("mpeg2_long_nonkey.m2v").write_bytes(data[:starts[0]] + data[starts[1]:])

ffmpeg -fflags +genpts -r 10 -i mpeg2_long_nonkey.m2v \
  -f lavfi -i "sine=frequency=440:sample_rate=48000:duration=8" \
  -c:v copy -copyinkf -c:a aac -b:a 32k -shortest -mpegts_copyts 1 \
  -f mpegts mpeg2_nonkey_aac.ts
